# Deterministic Signing Episodes — Typography

The project uses a deterministic, minimal, and reproducible typography system.
Fonts are selected to match the geometric, technical, and cryptographic nature
of the project, consistent with the Krunixbase ecosystem and SeedTools.

## Primary Font

### **Inter**
A clean, modern sans‑serif font used for all UI elements, badges, documentation,
and general text.  
- High readability  
- Neutral geometry  
- Excellent for technical projects  
- Works well in both dark and light themes  

Recommended weights:
- Regular (400)
- Medium (500)
- SemiBold (600)

## Code & Technical Font

### **JetBrains Mono**
A monospaced font used for code blocks, CLI output, API documentation, and
developer‑focused sections.  
- Crisp monospacing  
- Clear distinction between characters  
- Ideal for cryptographic and deterministic workflows  

Recommended weights:
- Regular (400)
- Medium (500)

## Alternative Font (Optional)

### **Roboto Mono**
Used as a fallback monospaced font when JetBrains Mono is unavailable.  
- High compatibility  
- Clean and readable  
- Works well in documentation and code samples

## Usage Guidelines

- Use **Inter** for all headings, paragraphs, badges, and UI text.
- Use **JetBrains Mono** for code, API examples, CLI output, and configuration files.
- Avoid mixing multiple sans‑serif fonts to maintain deterministic consistency.
- Keep typography minimal — no decorative fonts, no stylistic randomness.
- Maintain consistent spacing and line height across documentation.

## Deterministic Principle

Typography follows the same deterministic philosophy as the rest of the project:
- One primary sans‑serif font  
- One primary monospaced font  
- No randomness in style, weight, or spacing  
- Fully reproducible across all environments
