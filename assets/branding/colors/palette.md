# Deterministic Signing Episodes — Color Palette

A minimal, deterministic color palette used across the entire branding system.
All colors follow the geometric, reproducible design language consistent with the
Krunixbase ecosystem and SeedTools.

## Primary Colors

- **Primary Black**  
  `#000000`  
  Main background for badges, dark UI elements, and technical documentation.

- **Primary White**  
  `#FFFFFF`  
  High‑contrast background for light variants, PNG exports, and documentation pages.

## Accent Colors

- **Deterministic Green (Krunixbase Accent)**  
  `#00FF88`  
  Primary accent color used for nodes, connections, icons, and deterministic markers.

- **Deterministic Green Light**  
  `#00AA55`  
  Accent variant optimized for light backgrounds and light badge versions.

## Neutral Colors

- **Dark Grey**  
  `#111111`  
  Minimalist background for standard badges and dark UI blocks.

- **Light Grey**  
  `#F5F5F5`  
  Neutral background for documentation, README sections, and wiki pages.

## Usage Guidelines

- Use **Deterministic Green (`#00FF88`)** as the main accent for icons and deterministic elements.
- Use **Green Light (`#00AA55`)** for light backgrounds and light badge variants.
- Badge backgrounds:
  - Dark → `#000000`
  - Light → `#FFFFFF`
- SVG icons should remain monochrome (white + green).
- PNG exports must preserve original colors without gradients.

## Deterministic Principle

Each color has a single, deterministic purpose:
- **Primary** → structural elements  
- **Accent** → deterministic signature  
- **Neutral** → documentation backgrounds  

No randomness. No gradients in technical variants. Fully reproducible.
