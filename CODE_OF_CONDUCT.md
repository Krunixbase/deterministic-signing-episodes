# Code of Conduct
## Our Pledge
We are committed to providing a welcoming, safe, and professional environment for everyone.  
This project is built on transparency, reproducibility, and respect — and we expect contributors to uphold these values.

## Our Standards
Examples of behavior that contributes to a positive environment:
- Using respectful and inclusive language
- Providing constructive feedback
- Accepting responsibility for mistakes
- Focusing on deterministic, reproducible, and auditable contributions
- Collaborating openly and professionally

Examples of unacceptable behavior:
- Harassment or discrimination
- Personal attacks or insults
- Publishing private information without permission
- Introducing nondeterministic or malicious code
- Disruptive or unprofessional conduct

## Our Responsibilities
Project maintainers are responsible for:
- Reviewing contributions fairly
- Enforcing this Code of Conduct
- Maintaining a safe and transparent environment
- Rejecting contributions that violate determinism or security guarantees

## Scope
This Code of Conduct applies to:
- All project spaces (GitHub issues, PRs, discussions)
- All interactions related to the project
- All contributors, maintainers, and external reviewers

## Enforcement
Instances of abusive, unacceptable, or unsafe behavior may be reported to:

**krunixbase@gmail.com**

All reports will be reviewed and handled confidentially.

## Consequences
Maintainers may take actions including:
- Warning the contributor
- Reverting or rejecting contributions
- Temporary or permanent bans from project spaces
- Escalation to platform administrators if necessary
